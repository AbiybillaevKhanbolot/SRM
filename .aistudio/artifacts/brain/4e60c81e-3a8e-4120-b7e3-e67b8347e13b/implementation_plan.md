# Staff Control CRM — Система учёта рабочего времени и активности сотрудников

Полноценная современная CRM-система для внутреннего операционного контроля рабочего времени, прихода/ухода, перерывов на обед, времени отдыха и статистики звонков 17 сотрудников организации под управлением заместителя руководителя Айгерим.

---

## User Review & Critical Decisions

> [!IMPORTANT]
> **Подтверждённые решения из Фазы 1:**
> - **Стандартный рабочий график:** с 09:00 до 18:00 (автоматический расчёт опоздания при приходе позже 09:00).
> - **Стандартный обеденный перерыв:** 45 минут (автоматический расчёт перерасхода времени обеда при возвращении позже положенного).
> - **База данных:** Облачная база данных Firebase Firestore с коллекциями `employees`, `attendance`, `lunch`, `breaks`, `calls`, `users` и `settings` для постоянного сохранения всей ежедневной истории.
> - **Механизм выбора времени:** Интерактивный Wheel Time Picker (колёсная прокрутка часов и минут в стиле iOS) во всех модулях ввода времени.

## 1. Overview & Core Concept

- **Назначение системы:** Предоставить заместителю руководителя Айгерим («зам замыч») оперативный и удобный инструмент ежедневного мониторинга дисциплины, прихода/ухода, обедов, пауз на отдых и эффективности телефонных звонков.
- **Целевая аудитория:** Заместитель руководителя Айгерим (роль Администратор), руководство организации.
- **Ключевая ценность:** Быстрый ввод в 1–2 клика с помощью эргономичного Wheel Time Picker, моментальный автоматический пересчёт опозданий и таймингов, отсутствие потерь данных при перезагрузке, сводные отчёты и выгрузка за любой выбранный рабочий день.

## 2. User Experience & Visual Design

### Архитектура интерфейса и навигации
- **Рабочий холст:** Левый адаптивный сайдбар (260px) с фирменным логотипом Staff Control, навигацией по 6 разделам и карточкой профиля Айгерим (Заместитель руководителя) с кнопкой защищённого выхода.
- **Верхняя строка управления:** Текущая дата и живые часы (в формате `HH:mm:ss`), быстрый фильтр по дате, кнопка быстрого добавления записи и индикатор статуса синхронизации базы данных.
- **Эстетика (SaaS Linear & Apple Design):**
  - *Фоновая палитра:* Светлый ультрачистый холст `#F7F8FA`, белые карточки `#FFFFFF` с мягкими тенями `shadow-xs`/`shadow-sm` и субмикронными границами `border-slate-200/80`.
  - *Акцентные цвета:* Индиго/фиалковый акцент `#6366F1` (бренд и активные элементы), изумрудный `#16A34A` (вовремя/норма), янтарный `#F59E0B` (опоздание/в процессе), кораллово-красный `#EF4444` (пропущенные/отсутствие).
  - *Типографика:* Шрифт заголовков `Plus Jakarta Sans`, текст интерфейса `Public Sans` / `DM Sans`, числовые показатели и тайминги строго с моноширинными цифрами `tabular-nums` / `JetBrains Mono`.

### Дизайн компонентов
- **iOS Wheel Time Picker Modal:** Фирменный барабанный селектор времени с плавной инерционной прокруткой, тактильными делениями, центральной фокусирующей линзой и раздельными колонками для часов (00–23) и минут (00–59), с кнопками быстрой фиксации («Сейчас», «09:00», «13:00», «18:00») и кнопкой «Применить».
- **Интерактивные таблицы сотрудников:** Высота строк 44–48px, чёткая контрастность, подсветка при наведении, мгновенные модальные окна редактирования и удаления с диалогом подтверждения.

## 3. Key Product Decisions & Trade-Offs

1. **Безопасная авторизация Base44:**
   - *Подход:* Администратор `Admin` / `Admin007` аутентифицируется через криптографическое хэширование с солью и безопасное Base44-кодирование токенов сессии. Пароль никогда не отображается и не хранится в открытом виде.
   - *Плюсы:* Соответствие строгим требованиям ТЗ, защита сессии в `localStorage`/`sessionStorage` с автоматическим продлением и безопасным выходом.

2. **Облачное хранение Firestore + Оффлайн кэш:**
   - *Подход:* Подключение Firebase Firestore с автоматической начальной синхронизацией 17 предопределённых сотрудников и реактивными подписками `onSnapshot`.
   - *Плюсы:* Данные не зависят от локального устройства, синхронизируются мгновенно, не исчезают при перезагрузке и сохраняют полную историю за все предыдущие дни.

3. **Wheel Time Picker без сторонних тяжелых библиотек:**
   - *Подход:* Собственный легковесный высокопроизводительный React-компонент с поддержкой колесика мыши, тач-свайпа и клавиатурных стрелок, стилизованный в духе iOS Cupertino Wheel Picker.
   - *Плюсы:* Идеальная адаптивность на смартфонах, планшетах и десктопах, отсутствие багов версий и нулевая задержка открытия.

### Модели данных (Firestore Collections)

1. **`employees`**:
   `{ id: string, name: string, is_active: boolean, created_at: string, position?: string }`
   *Автоматически создаются 17 сотрудников: Айгуль, Хан, Айзат, Айдай, Малика, Арина, Эльзира, Байел, Тунук, Наргиз, Айдана, Курсант, Айпери, Эльнура, Санжар, Айсалкын, Рамазан.*
2. **`attendance`**:
   `{ id: string, employee_id: string, date: "YYYY-MM-DD", arrival_time: "HH:mm", departure_time: "HH:mm", lateness_minutes: number, status: "on_time" | "late" | "absent", created_at: string, updated_at: string }`
3. **`lunch`**:
   `{ id: string, employee_id: string, date: "YYYY-MM-DD", lunch_start: "HH:mm", planned_return: "HH:mm", actual_return: "HH:mm", duration_minutes: number, lateness_minutes: number, status: "on_time" | "overdue" | "in_progress", created_at: string, updated_at: string }`
4. **`breaks`**:
   `{ id: string, employee_id: string, date: "YYYY-MM-DD", break_start: "HH:mm", break_end: "HH:mm", duration_minutes: number, status: "in_progress" | "completed", created_at: string, updated_at: string }`
5. **`calls`**:
   `{ id: string, employee_id: string, date: "YYYY-MM-DD", accepted_calls: number, missed_calls: number, total_calls: number, created_at: string, updated_at: string }`
6. **`users`**:
   `{ id: string, username: "Admin", role: "admin", employee_name: "Айгерим", position: "Заместитель руководителя", password_hash: string, created_at: string }`
7. **`settings`**:
   `{ work_start: "09:00", work_end: "18:00", standard_lunch_minutes: 45 }`

### План пошаговой реализации:
1. Инициализация базы данных и Firebase конфигурации со схемой коллекций и правилами безопасности.
2. Реализация защищённой авторизации Base44 с сессией администратора Айгерим.
3. Разработка интерактивного барабанного селектора времени (Wheel Time Picker в стиле iOS).
4. Разработка глобального контекста данных с автоматическим расчётом метрик, опозданий, перерывов и синхронизацией в реальном времени.
5. Создание модулей CRM: Главная панель (Dashboard), Приход, Обед, Тайм (с живым таймером), Звонки, Сотрудники.
6. Разработка раздела «История и отчёты» с фильтрами по датам/сотрудникам и экспортом в Excel (CSV) и PDF.
7. Проверка сборки и линтинга (`compile_applet` + `lint_applet`), верификация всех пользовательских сценариев.
